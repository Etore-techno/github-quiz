SITE : Codes binaires - cours, démonstrations, animations et exercices

Contenu des fichiers :
- index.html : la page principale du site
- styles.css : la mise en forme
- script.js : les animations, manipulations et corrections automatiques

Utilisation :
1. Dézipper le dossier si nécessaire.
2. Ouvrir le fichier index.html dans un navigateur récent.
3. Aucun serveur n'est nécessaire.
4. Aucune connexion Internet n'est nécessaire.

Activités incluses :
1. Calculatrice binaire : chaque touche est codée sur 4 bits.
2. Bitmap noir et blanc : 0 = blanc, 1 = noir.
3. Bitmap couleur : chaque couleur est codée sur 3 bits.
4. Code ASCII : chaque lettre correspond à un nombre, puis à un code binaire sur 8 bits.
5. Stick de manette : la position du stick est représentée par deux valeurs X et Y codées sur 3 bits.

Remarques pédagogiques :
- Le site simplifie certains fonctionnements pour les rendre accessibles à des collégiens.
- Les simplifications sont signalées dans les parties cours.
- Les activités sont prévues pour une utilisation projetée en classe ou en autonomie sur ordinateur.
