Idée générale à retenir

Un ordinateur manipule seulement des informations numériques. Selon le contexte, les mêmes 0 et 1 peuvent représenter une touche, un pixel, une lettre, une couleur ou la position d’un capteur.

Activité 1 — Simuler une calculatrice

Avant de comprendre la calculatrice, on commence par voir comment circulent des 0 et des 1. Ensuite, on suit pas à pas ce qui se passe quand on tape 3 + 5 =.

Avant la calculatrice — comment circulent les 0 et les 1 ?

Dans un circuit numérique simplifié, on distingue deux états : un niveau bas (que l’on associe à 0) et un niveau haut (que l’on associe à 1). Pour les élèves, on peut retenir :

  • Interrupteur ouvert → niveau bas → 0
  • Interrupteur fermé → niveau haut → 1

Activité 2 — Image bitmap noir et blanc

Une image peut être découpée en pixels. En noir et blanc, un seul bit suffit pour coder chaque pixel.

Cours

Une image bitmap est une grille de pixels. Dans cet exemple simplifié : 0 signifie blanc et 1 signifie noir.

Le code est lu ligne par ligne. Sur une image 8 × 8, chaque ligne contient 8 bits.

Activité 3 — Image bitmap couleur

        
Pour coder une couleur, il faut plus d’informations qu’un simple 0 ou 1.

      


      

        

          
Cours

          
Ici, chaque pixel est codé par un groupe de 3 bits. Avec 3 bits, on peut créer 8 codes différents, donc 8 couleurs dans notre palette simplifiée.

          
Dans une vraie image, on utilise souvent le modèle RVB : rouge, vert, bleu. Chaque pixel contient alors beaucoup plus de bits.

Activité 4 — Texte en code ASCII

        
Un ordinateur associe un nombre à chaque caractère. Ce nombre peut ensuite être écrit en binaire.

      


      

        

          
Cours

          
Le code ASCII est une table de correspondance entre des caractères et des nombres. Par exemple, la lettre A correspond au nombre 65, qui s’écrit 01000001 en binaire sur 8 bits.

          
Pour décoder un mot, on lit chaque bloc de 8 bits.

Activité 5 — Stick de manette de jeu

        
Un stick ne donne pas seulement une direction. Il fournit deux valeurs numériques : une pour l’axe X et une pour l’axe Y.

      


      

        

          
Cours

          
Un stick analogique mesure une position. Pour simplifier, on transforme cette position en deux nombres de 0 à 7.

          
Chaque nombre de 0 à 7 peut être codé sur 3 bits. La position du stick est donc représentée par deux codes binaires : un pour X et un pour Y.
