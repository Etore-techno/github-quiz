Projet : Chaînes d’information et d’énergie
Niveau : 3e

Fichiers principaux :
- index.html : page web de l’activité
- styles.css : mise en page fixe 1920 x 1080 et styles visuels
- script.js : fonctionnement des exercices, menus de réponses, vérification, notes et zoom image
- assets/ : images utilisées dans les exercices

Fonctionnement :
- Les exercices se font dans l’ordre : panneau solaire, éolienne, chauffage électrique.
- L’élève doit compléter toutes les zones avant de vérifier.
- Les bonnes réponses sont verrouillées.
- Les mauvaises réponses sont à refaire.
- La note affichée en haut à droite correspond uniquement à l’exercice en cours.
- Les trois notes sont affichées uniquement lorsque les trois exercices sont terminés.
- La page est conçue dans une scène fixe de 1920 x 1080 px qui se met automatiquement à l’échelle de la fenêtre.
