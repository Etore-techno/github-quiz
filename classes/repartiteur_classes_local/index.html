3. Paramètres de classes

Élèves faisant allemand + latin

Ces élèves sont traités comme une contrainte forte : ils ne peuvent aller que dans les classes cochées. La classe par défaut est utilisée en priorité, sauf si cela empêche de respecter les quotas.

Exemples : 5e1: alld=9; latin=7 ou 5e3: effectif=27. Ces écarts sont très fortement pénalisés.
